## Limits

Ordinary missing animation clips and optional animation bone warnings remain recorded in the full JSON reports. Some cause missing movement/look effects; some are optional channels present in upstream assets. They are not silently classified as successful rendered tests. Static checks cannot exercise every runtime expression, animation transition, driver or third-party render mixin.

Run the maintained scanner before future pack updates:

```sh
python3 tools/audit_installed_models.py --profile "/path/to/instance" --overlay dist/resource-pack.zip --output reports/runtime-audit
```

Its compiled poser inventory is tied to the official Cobblemon jar hash and fails closed when the jar changes. Refresh the inventory for a new Cobblemon version; never reuse a mismatched one.
