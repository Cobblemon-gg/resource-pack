## Client/server split acceptance checks

- [ ] New client starts with the built-in baseline enabled and renders tags, inventories and existing skins without a server pack.
- [ ] Join using the small overlay, verify fonts/inventory screens and several ordinary/custom Pokémon.
- [ ] Change one existing skin and add one new tag/resolver at its normal source path, rebuild only the server pack, and verify both without a client update.
- [ ] Delete a temporary custom-only resource and its references; verify the generated resource filter hides the client baseline copy.
- [ ] Verify the complete fallback pack on a client without the baseline before transitioning older clients.

Baseline bundling removes the large repeated download. Minecraft may still reload all packs when joining; it does not remove all reload time or GPU texture memory usage.
